# Objetivo
Revisar el flujo indicado en FOCUS y determinar si mezcla finalidades de consentimiento en un solo checkbox/acción, si condiciona la transacción a tratamientos no esenciales, o si el consentimiento no es libre/específico/informado.

# Pasos
1. Identificar cada checkbox/acción de aceptación presente en el flujo
2. Para cada uno, listar qué finalidades agrupa (T&C, privacidad, tratamiento de datos, marketing, terceros...)
3. Marcar como infracción cualquier agrupación de finalidades distintas en una sola acción
4. Proponer la separación mínima necesaria (ver skill de consentimiento granular)
5. Estimar el riesgo regulatorio (multas de referencia si aplica)

# Formato de respuesta
Resumen ejecutivo (2-3 líneas) → lista de infracciones (formato del agente) → checklist de corrección priorizado
