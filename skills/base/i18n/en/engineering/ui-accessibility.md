# Objective

Accessibility review. Standard: WCAG 2.1 AA
KISS+DRY: see `kiss-dry-core.md`.

# Skill: UI accessibility
Semantic HTML before ARIA (button, label, nav…). Every control keyboard-operable with visible focus. AA contrast (4.5:1 for text). Alt on informative images; labels tied to inputs; errors linked to their field. Never convey information by color alone.
