# Skill: Accesibilidad UI
HTML semántico antes que ARIA (button, label, nav…). Todo control operable con teclado y con foco visible. Contraste AA (4.5:1 en texto). Alt en imágenes informativas; labels asociados a inputs; errores vinculados al campo. No transmitir información solo con color.
